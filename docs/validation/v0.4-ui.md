End-to-end validation of the Read + Review UI against a **live server** and real run folders.
Every line is labelled **Executed** (run against the running server / on-disk files) or
**Design-only** (exercised through the identical HTTP endpoints rather than a rendered browser
session, or covered by the automated suite). No results are invented.

## Setup (Executed)

- Local mock bot started on `127.0.0.1:8199` (`tests/mockbot.py`); preflight `suite validate` OK.
- Fresh run produced: `uv run suite run --endpoint endpoints/mock.yaml --pack prompts/smoke` →
  run folder `results/20261028-053831-mock`, draft report + `review.csv` with **2 needs-review**
  attempts (`SMK-006#1`, `SMK-007#1`).
- UI launched: `uv run suite web --results results --port 8788` (port checked free first, bound to
  `127.0.0.1`). `results/` already held 5 earlier runs (mock + lab-bot), so the read views had
  genuine multi-run data.

### Browser ↔ CLI interchangeability (Executed — the key check)

After finalizing **in the UI**, running the engine's own `uv run suite finalize --run
results/20261028-053831-mock` on the same folder reported `applied 2, pending 0` and produced a
**byte-identical `report.md`** (`diff` clean). This confirms the browser and the CLI act on the
same `review.csv` through the same `finalize()` — they are interchangeable, exactly as specced.

## Security guards (Executed — live)

| Attack | Result |
|---|---|
| Cross-origin write: `POST …/finalize` with `Origin: http://evil.example` | **403** (refused) |
| Path traversal: `GET /api/v1/runs/..%2F..%2Fsecret` | **404** |
| DNS-rebinding: any request with `Host: evil.example` | **400** |

## Design-only / covered-by-suite

- **Rendered browser click-through** (visual layout, HTMX fragment swaps, Pass/Fail button
  state): the identical HTTP endpoints were driven via `curl`, not a real browser session —
  **Design-only** here. The HTML pages returned 200 with the expected data.
- **Inert rendering** (a bot reply containing `<script>` renders escaped): covered by the
  automated suite (`tests/test_web_views.py::test_reply_with_script_is_escaped`), not re-exercised
  here — **Design-only** at this step.
- **`suite web` Ctrl+C message** and the non-loopback `--host` behaviour: covered by
  `tests/test_web_cli.py` / `tests/test_web_security.py`; not run interactively here.

## Verdict

**Executed validation passed.** The UI reads real runs, renders the OWASP report + coverage +
compare, performs the human-review write-back and finalize, stays byte-for-byte interchangeable
with the CLI, and enforces its same-origin / trusted-host / traversal guards live. No defects
found during validation.

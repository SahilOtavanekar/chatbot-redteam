# v0.3 Phase A — LLM05 + LLM06 baseline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the `suite import` baseline to cover OWASP **LLM05** (Improper Output Handling) and **LLM06** (Excessive Agency) by importing four bundled garak payload datasets as-is and judging the replies with PyRIT output scorers, and make the importer prune stale generated files so a changing category set stays correct.

**Architecture:** Pure additions on the v0.2 importer. Wire `ShellCommandOutputScorer` into the detector registry (`xss_output`/`markdown_injection` already wired), add four rows to the committed mapping table, add stale-file pruning to `importer.py`. Payloads are sent as-is (garak ships no carriers); each LLM05/06 prompt carries exactly its output detector, so it is rule-judged, never silently passed.

**Tech Stack:** Python 3.13, uv, `pyrit==1.1.0` (behind `adapters/` only), pydantic v2, PyYAML.

**Spec:** `docs/specs/2026-10-26-v0.3-owasp-coverage-design.md` (read §2 contract, §5 Phase A, §6 pruning — this plan is **Phase A** only).

## Global Constraints

- Python `>=3.13`; `pyrit==1.1.0`; **only `src/suite/adapters/` imports `pyrit`** (`tests/test_boundary.py`).
- **No attack text in the repo or tests.** The importer moves garak's text file→file; tests use **benign fixture datasets** (`tests/fixtures/garak/*.prompt`) with innocuous payload-shaped content (e.g. a harmless `<b>hi</b>` snippet, the command `echo hi`).
- Deterministic judging; **Inconclusive / needs-review is never a Pass.** Each LLM05/06 prompt carries its output detector, so `checks.is_empty()` is false → it is judged, never routed to review for lack of a check.
- Generated `prompts/baseline/` is git-ignored; the map and code are committed. Deterministic, byte-identical, atomic writes.
- Detector names come from `suite.prompts.DETECTOR_NAMES`; the map/registry sync test (v0.2 `tests/test_importer_map.py::test_every_row_is_valid`) must keep passing — a map row may name only a wired detector.
- Never run `git checkout/reset/restore/clean/stash`; TDD; commit per task on `feat/v0.3-owasp-coverage`; end commit messages with `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`. Subagents must not print real garak/baseline prompt bodies.

## Review Focus

1. **A new map row names a detector that isn't wired** → the sync test must fail (map can't reference an unwired detector); after Task 1 all four rows resolve. → Task 2 relies on `test_every_row_is_valid`.
2. **An LLM05/06 prompt ending with no check** would route to review or (worse) look like a pass-by-default — every imported LLM05/06 prompt must carry exactly its output detector and no canary. → Task 2 `test_llm05_06_prompts_carry_their_detector_and_no_canary`.
3. **Stale pruning deletes a user's own file** in `--out` → pruning removes only the generated pattern (`LLM\d\d.yaml`, `COVERAGE.md`), never other files. → Task 3 `test_pruning_leaves_unmanaged_files`.
4. **Re-import after the map shrank** leaves a stale `LLM0x.yaml` that a later run picks up → pruning removes it. → Task 3 `test_stale_generated_file_is_pruned`.
5. **`shell_command_output` false trip on ordinary prose** would turn a clean reply into a Fail → the detector is clean on benign text, trips on shell-command output. → Task 1 `test_shell_command_output_detector`.

### Task 3: Stale-file pruning in the importer

**Files:**
- Modify: `src/suite/importer.py`
- Test: `tests/test_importer.py`

**Interfaces:**
- Produces: `import_source` removes the files it manages in `out_dir` before (or as part of) writing, so the output is exactly the current map's product. Managed pattern: file name matching `^LLM\d\d\.yaml$` plus `COVERAGE.md`. Any other file in `out_dir` is left untouched. Pruning happens only after all prompts validate (keep the fail-before-write property — a failed import must not delete a prior good baseline). Re-confirm the `load_pack(out_dir)` self-check still passes over exactly the written set.

- [ ] **Step 1: Write the failing tests.**

```python
def test_stale_generated_file_is_pruned(tmp_path):              # Review Focus 4
    out = tmp_path/"b"; out.mkdir(); (out/"LLM99.yaml").write_text("- id: X\n  category: LLM01\n  prompt: x\n", encoding="utf-8")
    import_source("garak", out, canary=CAN, base_dir=FIX)
    assert not (out/"LLM99.yaml").exists()
def test_pruning_leaves_unmanaged_files(tmp_path):              # Review Focus 3
    out = tmp_path/"b"; out.mkdir(); (out/"notes.txt").write_text("keep me", encoding="utf-8")
    import_source("garak", out, canary=CAN, base_dir=FIX)
    assert (out/"notes.txt").read_text(encoding="utf-8") == "keep me"
def test_a_failed_import_does_not_prune(tmp_path):              # fail-before-write preserved
    out = tmp_path/"b"; out.mkdir(); (out/"LLM07.yaml").write_text("prior", encoding="utf-8")
    with pytest.raises(ConfigError): import_source("garak", out, canary="ab", base_dir=FIX)   # short canary
    assert (out/"LLM07.yaml").read_text(encoding="utf-8") == "prior"
```

- [ ] **Step 3: Implement** pruning: after validation and before/with writing, delete `out_dir` files matching the managed pattern, then write the current set atomically. Do not touch unmanaged files; do not prune on a validation failure.
